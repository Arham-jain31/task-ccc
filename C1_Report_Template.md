## 4. Brief explanation
The C1 task extends the existing DEV@Deakin website with a New Post page. The user can choose Question or Article. React state is used to remember the selected type and input values. Conditional rendering shows the correct fields for each type. Basic validation checks the required fields and allows up to three tags. After valid input, a popup confirms that the post has been sent; the post is not stored because actual posting is outside this task.
